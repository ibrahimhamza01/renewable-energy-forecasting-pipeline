# Forecast Output Definition

## Purpose

This table stores batch wind forecast outputs generated by the approved production model.

## Grain

One row per:

- forecast date
- state
- target name
- model version

## Output Location

Logical path:

```text
forecasts.outputs
````

Resolved S3 path:

```text
s3a://<project_bucket>/forecasts/outputs
```

## Schema

| Column               |      Type | Nullable | Description                           |
| -------------------- | --------: | -------: | ------------------------------------- |
| forecast_id          |    string |       no | Unique forecast row identifier        |
| forecast_date        |      date |       no | Date being forecasted                 |
| region               |    string |      yes | Optional broader region               |
| state                |    string |       no | U.S. state abbreviation               |
| target_name          |    string |       no | Forecast target name                  |
| prediction           |    double |       no | Predicted wind capacity factor        |
| model_name           |    string |       no | Model name used for inference         |
| model_version        |    string |       no | Registered model version              |
| generation_timestamp | timestamp |       no | Timestamp when forecast was generated |
| horizon_days         |   integer |       no | Forecast horizon in days              |

## Partitioning

Forecast outputs are partitioned by:

```text
model_version
forecast_date
```

## Versioning Rule

Each batch forecast run writes to a timestamped run directory:

```text
forecasts/outputs/run_id=<UTC_TIMESTAMP>
```

Example:

```text
s3a://<project_bucket>/forecasts/outputs/run_id=20260504T071500Z
```

## Quality Expectations

* `forecast_id` must be non-null.
* `forecast_date` must be non-null.
* `state` must be non-null.
* `target_name` must be non-null.
* `prediction` must be non-null.
* `prediction` should usually be between 0 and 1.
* `model_version` must be non-null.
* `generation_timestamp` must be non-null.
