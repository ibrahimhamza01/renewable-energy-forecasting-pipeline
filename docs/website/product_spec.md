# Website Product Specification

## Product Name

Live Wind Forecasting Platform

## Product Goal

Turn the existing Wind Energy Forecasting Pipeline into a deployed portfolio-grade web product.

The website demonstrates:

- the original Spark/Airflow/ML pipeline
- historical wind analytics from gold tables
- model performance from exported pipeline artifacts
- live NOAA-powered wind potential estimation
- optional deployable ML inference using a portable model service

The final website must continue working even if EC2 and S3 resources expire.

---

## Target Users

### Primary users

- recruiters
- hiring managers
- data engineering reviewers
- ML engineering reviewers
- portfolio visitors

### Secondary users

- professors
- classmates
- renewable energy analysts
- technical interviewers

---

## Core Product Positioning

It is a portfolio-grade data product showing how a large-scale Spark pipeline can produce durable analytics, model outputs, and live-facing forecast functionality.

The website acts as the presentation layer for the pipeline.

The pipeline produces curated outputs.

The website displays and explains those outputs.

---

## What the Website Is

The website is:

- a live portfolio dashboard
- a visualization layer for the wind pipeline
- a demonstration of the data lake architecture
- a dashboard for precomputed Spark/Airflow/ML artifacts
- a live wind potential estimator using NOAA observations and power-curve logic
- optionally, a deployed ML inference interface using a portable non-Spark model

---

## What the Website Is Not

The website is not:

- a replacement for the Spark pipeline
- a replacement for Airflow orchestration
- a browser-based Spark application
- a full retraining system
- a live Spark MLlib model server
- a real-time grid operations system

---

## Allowed Claims

The website may claim:

- The historical analytics were produced by a Spark-based NOAA ISD pipeline.
- The pipeline uses Bronze, Silver, and Gold-style data lake layers.
- The forecasting model was trained using engineered gold-layer features.
- The dashboard displays exported artifacts from the production-style pipeline.
- The live explorer estimates wind potential from current NOAA observations.
- The live estimate uses the same power-curve methodology used in the project.
- A portable deployed model service may provide live ML-style predictions if implemented.

---

## Disallowed Claims

The website must not claim:

- that the browser runs Spark
- that the live NOAA estimator is the same as the Spark GBT model
- that the site performs full historical feature engineering in real time
- that the site retrains models live
- that the site is a production grid forecasting service
- that it serves a Spark MLlib model directly unless Spark is actually deployed behind the API

---

## Required Wording

Use:

> Live wind potential estimate using NOAA observations and power-curve logic.

Do not use:

> Live Spark GBT forecast.

Unless a real deployed inference API exists and the wording clearly explains that it is a portable model service, not Spark MLlib running in the browser.

## Live vs Precomputed Behavior

### Live components

The website may fetch:

- latest NOAA/NWS station observations
- current wind speed
- current wind direction
- current temperature

The live estimator computes:

- power-curve capacity factor
- current wind potential estimate

### Precomputed components

The website displays precomputed outputs from:

- gold wind analytics tables
- forecast validation outputs
- model metrics
- benchmark outputs
- exported figures

These files should live in:

```text
website/public/data/
website/public/assets/
docs/assets/
website_data/
````
